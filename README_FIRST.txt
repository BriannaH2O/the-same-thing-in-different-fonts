TO PUBLISH VIA GITHUB PAGES:

3. Upload the CONTENTS of this ZIP into the repository's root (not the enclosing folder). Keep the documents folder structure.
4. In repository Settings > Pages, choose Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
5. The expected project-site URL pattern is https://BriannaH2O.github.io/the-same-thing-in-different-fonts/ (not live until deployment succeeds).
6. For future changes: replace edited files in the same repository, commit, and Pages will redeploy.
